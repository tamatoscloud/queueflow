# queueflow_widgets

Composed, reusable widgets (`EmptyStateView`, `LoadingOverlay`) built from `queueflow_ui` primitives and `queueflow_theme` tokens.

**Depends on:** `queueflow_ui`, `queueflow_theme`, `queueflow_utils`.

This is the "molecules/organisms" layer. No business logic and no screens — screens are composed inside each app's `features/<feature>/presentation/`.
